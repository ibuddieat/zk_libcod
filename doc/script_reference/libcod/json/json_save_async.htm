json_save_async( <fs path>, <value>, [<pretty>] )

Module: JSON

Summary:

Behaves like json_save, but does not freeze the server while the file writes. Returns a job ID (1 or higher), or 0 if it could not start. Keep checking json_async_done until the returned job ID shows up, then json_async_result returns whether it worked (1) or not (0).



Example:

job = json_save_async("stats/match.json", level.matchLog, 1);
// later, once done[i] == job:
ok = json_async_result(job);



Required Args:

  • 1 : <fs path> Where to write the file, a path relative to the mod folder. Avoid a leading slash and dot-dot sequences
  • 2 : <value> The GSC data to save. Supported types are: struct, array, string, integer, float, vector

Optional Args

  • 3 : <pretty> Output style: 0 = compact single-line (default), 1 = human-readable multi-line
