json_save_async( <fs path>, <value>, [<pretty>] )

Module: JSON

Summary:

Behaves like json_save, but writes the file in the background. Returns a job ID, or 0 if the job could not start. Keep checking json_async_done until the job ID shows up, then json_async_result returns 1 (saved) or 0 (failed).

Claiming the result is optional. Only the newest 1024 finished saves are kept; an older unclaimed one is dropped (a failed one prints why to the console first). On server quit, saves still running are finished first (up to 5 seconds).



Example:

job = json_save_async("stats/match.json", level.matchLog);



Required Args:

  • 1 : <fs path> Path relative to the mod folder
  • 2 : <value> The data to save

Optional Args

  • 3 : <pretty> 1 for readable multi-line output, 0 (default) for one line
