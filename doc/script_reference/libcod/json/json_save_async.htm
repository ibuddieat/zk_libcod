json_save_async( <fs path>, <value>, [<pretty>] )

Module: JSON

Summary:

Like json_save, but it does not freeze the server while the file writes. Your data is copied right away, then the writing happens in the background and you get a jobId back. Keep checking json_async_done() until your jobId shows up, then json_async_result() tells you if it worked (1) or not (0). Returns a jobId (1 or higher), or 0 if it could not start.



Example:

job = json_save_async("stats/match.json", level.matchLog, 1);
// later, once done[i] == job:
ok = json_async_result(job);



Required Args:

  • 1 : <fs path> Where to write the file, relative to the mod folder. No leading / and no ...
  • 2 : <value> The GSC data to save (struct, array, string, int, float, vec3).

Optional Args

  • 3 : <pretty> 0 compact single-line (default), 1 readable multi-line.
