json_load_async( <fs path> )

Module: JSON

Summary:

Like json_load, but it does not freeze the server while the file loads. The reading happens in the background and you get a jobId back right away. Keep checking json_async_done() until your jobId shows up, then grab the data with json_async_result(). Returns a jobId (1 or higher), or 0 if it could not start (bad path, too many jobs running).

Use this for big files. It only reads loose files in your mod folder, not files packed inside .iwd archives, for those use json_load. A file holding more than 32768 values fails the job (the script variable pool cannot hold more), so json_async_result() returns undefined.



Example:

job = json_load_async("stats/big.json");
if(job == 0) return;
// later, once done[i] == job:
value = json_async_result(job);

  • 1 : <fs path> Path to the file, relative to the mod folder. No leading / and no ...
