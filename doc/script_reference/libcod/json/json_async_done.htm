json_async_done( )

Module: JSON

Summary:

Gives you a list of jobIds (from json_load_async / json_save_async) that have finished. The list is empty if nothing is ready yet. Cheap to call, so check it on a timer. A jobId keeps showing up until you collect it with json_async_result().



Example:

for(;;)
{
    wait 0.5;
    finished = json_async_done();
    for(i = 0; i < finished.size; i += 1)
        result = json_async_result(finished[i]);
}
