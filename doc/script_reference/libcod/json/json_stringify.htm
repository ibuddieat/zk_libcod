json_stringify( <value>, [<pretty>] )

Module: JSON

Summary:

Turns GSC data into a JSON string. Arrays numbered 0, 1, 2, ... become lists, other arrays and structs like level or SpawnStruct become objects, and vectors become a list of 3 numbers. Returns undefined if the result would be 65000 bytes or more (use json_save for larger data).

Note: Struct field names are written in lowercase. Entities, players and function pointers are written as null.



Example:

a = [];
a["name"] = "bot1";
a["pos"]  = (12.5, 34.0, 56.0);
s = json_stringify(a, 1);



Required Args:

  • 1 : <value> The data to convert

Optional Args

  • 2 : <pretty> 1 for readable multi-line output, 0 (default) for one line
