json_stringify( <value>, [<pretty>] )

Module: JSON

Summary:

Turns GSC data back into a JSON string. A numbered array becomes a JSON list; anything else becomes a JSON object. Pass pretty = 1 for readable multi-line output, or leave it out for a compact one-liner.



Example:

a = [];
a["name"] = "bot1";
a["pos"]  = (12.5, 34.0, 56.0);
s = json_stringify(a, 1);



Required Args:

  • 1 : <value> Any GSC value: struct, array, string, int, float, or vec3.

Optional Args

  • 2 : <pretty> 0 compact single-line (default), 1 readable multi-line.
