json_parse( <json string> )

Module: JSON

Summary:

Reads JSON text and returns it as GSC data. Objects become arrays indexed by name like v["hp"], lists become arrays indexed by number like v[0], and true/false become 1/0. Returns undefined if the text is not valid JSON or too big for the script engine.

Note: Floats keep about 7 digits, so pass long numbers like player IDs as strings. JSON null comes back as undefined but still counts in .size.



Example:

v = json_parse("{\"name\":\"bot1\",\"hp\":100}");
IPrintLn(v["name"] + " has " + v["hp"] + " hp");



Required Args:

  • 1 : <json string> A string containing valid JSON
