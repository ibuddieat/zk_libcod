json_parse( <json string> )

Module: JSON

Summary:

Reads JSON text and turns it into GSC data. Returns a JSON object as an array that is indexed by name like v["hp"]; a JSON list comes back as an array indexed by number like v[0]. Returns undefined if the text is not valid JSON, or if it holds more than 32768 values.



Example:

v = json_parse("{\"name\":\"bot1\",\"hp\":100}");
IPrintLn(v["name"] + " has " + v["hp"] + " hp");



Required Args:

  • 1 : <json string> A string containing valid JSON
