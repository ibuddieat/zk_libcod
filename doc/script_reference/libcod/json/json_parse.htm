json_parse( <json string> )

Module: JSON

Summary:

Reads JSON text and turns it into GSC data. A JSON object comes back as an array you index by name (like v["hp"]); a JSON list comes back as an array you index by number (like v[0]). Returns undefined if the text is not valid JSON.



Example:

v = json_parse("{\"name\":\"bot1\",\"hp\":100}");
iprintln(v["name"] + " has " + v["hp"] + " hp");



Required Args:

  • 1 : <json string> A string containing valid JSON.
