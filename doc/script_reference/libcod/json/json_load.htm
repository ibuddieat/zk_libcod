json_load( <fs path> )

Module: JSON

Summary:

Reads a JSON file and turns it into GSC data. Returns undefined if the file is missing, the JSON is broken, or it holds more than 32768 values (the script variable pool cannot hold more), so check with isDefined() before using it. The server waits while the file loads, so keep files small (use json_load_async for big ones).



Example:

wp = json_load("waypoints/mp_carentan.json");
if(isDefined(wp))
    iprintln(wp["nodes"].size + " nodes loaded");



Required Args:

  • 1 : <fs path> Path to the file, relative to the mod folder.
