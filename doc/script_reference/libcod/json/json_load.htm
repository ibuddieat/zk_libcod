json_load( <fs path> )

Module: JSON

Summary:

Reads a JSON file and turns it into GSC data. Returns undefined if the file is missing, the JSON is broken, or it holds more than 32768 values, so it is advised to apply an IsDefined check before use. The server waits while the file loads, so keep the loaded files small to avoid server lag or use the non-blocking alternative json_load_async instead.



Example:

wp = json_load("waypoints/mp_carentan.json");
if(IsDefined(wp))
    IPrintLn(wp["nodes"].size + " nodes loaded");



Required Args:

  • 1 : <fs path> Path to the file, relative to the mod folder
