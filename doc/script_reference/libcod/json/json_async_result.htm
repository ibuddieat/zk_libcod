json_async_result( <jobId> )

Module: JSON

Summary:

Collects the result of a finished job. For a load job you get your data back (or undefined if it failed); for a save job you get 1 (worked) or 0 (failed). If the job is not done yet you get undefined and it stays in the queue, so you can check again later. Always collect every job you start, or it stays in memory.



Example:

job = json_load_async("stats/big.json");
// ... checking json_async_done() each tick ...
v = json_async_result(job);
if(isDefined(v))
    iprintln("loaded " + v["records"].size + " records");



Required Args:

  • 1 : <jobId> The number you got back from json_load_async or json_save_async.
