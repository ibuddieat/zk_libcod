json_async_result( <jobId> )

Module: JSON

Summary:

Collects the result of a finished json_load_async or json_save_async job. A load returns the data or undefined, a save returns 1 or 0. Returns undefined if the job is not finished yet or the ID is unknown.

Note: Collect every load you start, unclaimed results stay in memory until the next map load or fast_restart. Save results are kept for the newest 1024 finished saves only, so an old save ID can become unknown.



Example:

data = json_async_result(job);
if(IsDefined(data))
    IPrintLn(data.size + " entries loaded");



Required Args:

  • 1 : <jobId> Job ID from json_load_async or json_save_async
