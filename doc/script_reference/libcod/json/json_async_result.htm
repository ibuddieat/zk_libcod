json_async_result( <jobId> )

Module: JSON

Summary:

Collects the result of a finished json_load_async or json_save_async job. For a load job, the loaded data or undefined (on fail) is returned; for a save job, 1 (success) or 0 (fail) is returned. If the job is not done yet, undefined is returned and the job stays in the queue. Always collect every started job, or it stays in memory.



Example:

job = json_load_async("stats/big.json");
// ... checking json_async_done() each tick ...
v = json_async_result(job);
if(IsDefined(v))
    IPrintLn("loaded " + v["records"].size + " records");



Required Args:

  • 1 : <jobId> The numeric job ID returned from json_load_async or json_save_async
