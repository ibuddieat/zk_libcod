json_save( <fs path>, <value>, [<pretty>] )

Module: JSON

Summary:

Saves GSC data to a JSON file in the mod folder, like json_stringify. Missing folders are created, and the old file stays intact if the save fails. Returns 1 on success, otherwise 0. The server waits while the file writes, use json_save_async for big files.



Example:

ok = json_save("stats/players.json", stats, 1);



Required Args:

  • 1 : <fs path> Path relative to the mod folder
  • 2 : <value> The data to save

Optional Args

  • 3 : <pretty> 1 for readable multi-line output, 0 (default) for one line
