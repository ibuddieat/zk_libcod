json_save( <fs path>, <value>, [<pretty>] )

Module: JSON

Summary:

Saves GSC data to a JSON file inside your mod folder. Any missing folders in the path are created for you. Returns 1 if it worked, 0 if it failed. The server waits while the file writes, so keep files small (use json_save_async for big ones).



Example:

ok = json_save("stats/players.json", stats, 1);



Required Args:

  • 1 : <fs path> Where to write the file, relative to the mod folder.
  • 2 : <value> The GSC data to save (struct, array, string, int, float, vec3).

Optional Args

  • 3 : <pretty> 0 compact single-line (default), 1 readable multi-line.
