httpFetch( <url>, <method>, <data>, <extra headers>, <timeout seconds>, <onDone function>, <onError function> )

Module: Network

Summary:

Performs one asynchronous, non-blocking HTTP or HTTPS request and closes the connection once the response arrives. Exactly one callback runs exactly once: onDone(status, body, headers) on any reply (4xx/5xx included), or onError(error) on a network, DNS, TLS, timeout, invalid-URL or oversized-body failure. headers is an array indexed by lowercased name (e.g. headers["content-type"]); pair it with json_parse to read a JSON body. https:// is encrypted but the server certificate is not verified, so no system cert file is needed. Only the common standard response headers are returned (most APIs put their data in the body). A body larger than 65000 bytes - the biggest string GSC can hold - is refused with onError("response body too large"). An in-flight request finishes and frees itself even across a map change; its callback is dropped if the level that issued it has unloaded.



Example:

httpFetch("https://api.example.com/thing", "GET", "", "", 10, ::onDone, ::onError);

onDone(status, body, headers)
{
    data = json_parse(body);
    iprintln("status " + status);
}
onError(error)
{
    iprintln("request failed: " + error);
}



Required Args:

  • 1 : <url> The http:// or https:// URL. A missing port defaults to 80/443.
  • 2 : <method> "GET", "POST", etc. An empty string defaults to GET.
  • 3 : <data> The request body as text (a JSON string for example). GSC strings cannot carry an embedded NUL, so no binary body.
  • 4 : <extra headers> Extra request headers separated by \r\n, e.g. "Content-Type: application/json".
  • 5 : <timeout seconds> Whole-request timeout in seconds; 0 disables it.
  • 6 : <onDone function> Called as onDone(status, body, headers) on any reply.
  • 7 : <onError function> Called as onError(error) on failure.
