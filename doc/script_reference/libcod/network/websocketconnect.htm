webSocketConnect( <url>, <extra headers>, <onConnect function>, <onMessage function>, <onClose function>, <onError function>, [<reconnectDelayMs>], [<pingIntervalMs>] )

Module: Network

Summary:

Opens an asynchronous ws:// or wss:// WebSocket connection and returns a connection id (a slot index, 0..15) or -1 on error. Up to 16 connections may be open at once. Your callbacks run on the main thread: onConnect() when the handshake completes, onMessage(text) for each TEXT frame (binary frames are ignored), onClose(closedByRemote, fullyDisconnected), and onError(error). wss:// is encrypted but the certificate is not verified, so no system cert file is needed. Incoming messages larger than 65000 bytes (the max GSC string) are dropped. On an unexpected drop the client auto-reconnects after reconnectDelayMs, and a ping/pong watchdog closes a silently-dead link. All connections are closed automatically on map change or restart, so open them again from the new level's init.



Example:

id = webSocketConnect("wss://example.com/socket", "", ::onOpen, ::onMsg, ::onClose, ::onErr, 2000, 15000);

onOpen()          { webSocketSendText(level.wsId, "hello"); }
onMsg(text)       { iprintln("got: " + text); }
onClose(a, b)     {}
onErr(error)      { iprintln("ws error: " + error); }



Required Args:

  • 1 : <url> The ws:// or wss:// URL. A missing port defaults to 80/443.
  • 2 : <extra headers> Extra handshake headers separated by \r\n (empty for none).
  • 3 : <onConnect function> Called as onConnect() when connected.
  • 4 : <onMessage function> Called as onMessage(text) for each TEXT frame.
  • 5 : <onClose function> Called as onClose(closedByRemote, fullyDisconnected).
  • 6 : <onError function> Called as onError(error).

Optional Args

  • 7 : <reconnectDelayMs> Delay before auto-reconnect after a drop. Default 2000; 0 = connect once, no retry.
  • 8 : <pingIntervalMs> Keepalive ping interval. Default 15000; 0 = disabled.
