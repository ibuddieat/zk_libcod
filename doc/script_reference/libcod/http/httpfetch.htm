httpFetch( <url>, <method>, <data>, <headers>, <timeout>, <onDone>, <onError> )

Module: Http

Summary:

Sends an HTTP or HTTPS request and returns once the response arrives, without blocking the server. The connection is closed after the response is received. The request is driven on the main thread, so the callbacks run on the server thread and may safely use the script engine. Multiple requests can be in flight at the same time.

On completion the <onDone> callback is called with the status code, the response body and an array of response headers (keyed by header name). If the request fails (invalid URL, connection error, timeout) the <onError> callback is called with a descriptive message instead. Either callback may be passed as an undefined function to be ignored.



Example:

httpFetch("https://example.com/api", "POST", "{\"a\":1}", "Content-Type: application/json", 8000, ::onDone, ::onError);

onDone(status, body, headers)
{
    logPrintConsole("HTTP " + status + ": " + body + "\n");
}

onError(error)
{
    logPrintConsole("HTTP error: " + error + "\n");
}



Required Args:

  • 1 : <url> Target URL, http:// or https://
  • 2 : <method> HTTP method, e.g. "GET" or "POST"
  • 3 : <data> Request body, or an empty string for none
  • 4 : <headers> Extra request headers separated by \r\n, or an empty string for none
  • 5 : <timeout> Overall request timeout in milliseconds
  • 6 : <onDone> Script callback called on success with (status, body, headers)
  • 7 : <onError> Script callback called on failure with (error)
