ignoreWeapon( <weapon name> )

Module: Weapons

Summary:

Adds the specified weapon to the weapon ignore list so that it will not be loaded. Instead, defaultweapon_mp is loaded, unless overriden by setDefaultweapon. At most MAX_WEAPON_IGNORE_SIZE weapons can be added to the ignore list. The ignore list can be cleared with resetIgnoredWeapons. The list remains in memory until cleared or until the server is shut down. Returns true on success, otherwise undefined.



Example:

success = ignoreWeapon(weaponName);



Required Args:

  • 1 : <weapon name>: (string) The weapon name for this weapon
