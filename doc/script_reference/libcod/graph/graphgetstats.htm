graphGetStats( <graph id>, [<reset>] )

Module: Graph

Summary:

Returns per-graph counters as an array: [0] nodes, [1] edges, [2] searches, [3] partials, [4] expansions total, [5] expansions max, [6] us min, [7] us avg, [8] us max. Timings are microseconds per search.



Example:

s = graphGetStats(g);



Required Args:

  • 1 : <graph id> The graph.

Optional Args

  • 2 : <reset> If truthy, zero the counters after reading.
