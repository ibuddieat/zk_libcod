graphGetAllNodes( <graph id>, [<origin>], [<max. distance squared>] )

Module: Graph

Summary:

Returns an array of node ids. With an origin and a squared radius, only nodes within that radius are returned - a cheap spatial filter. Removed nodes are excluded.

Returns undefined when the result would exceed the script variable limit (32768 values). An auto-discovered map graph can exceed this, pass an origin and a maximum distance squared to narrow it in that case.



Example:

near = graphGetAllNodes(g, self.origin, 500 * 500);



Required Args:

  • 1 : <graph id> The graph

Optional Args

  • 2 : <origin> Filter center (world position)
  • 3 : <max. distance squared> Squared radius around origin; nodes farther than this are dropped
