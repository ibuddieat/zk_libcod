graphSetEdgeCost( <graph id>, <from>, <to>, <cost> )

Module: Graph

Summary:

Sets the traversal cost of a directed edge - the main hook for danger-weighting. Returns true, or false if the edge does not exist. Cost must be non-negative; keep it at or above the physical distance so the A* heuristic stays admissible.



Example:

graphSetEdgeCost(g, 0, 1, 9999);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <from> Source node.
  • 3 : <to> Destination node.
  • 4 : <cost> New non-negative cost.
