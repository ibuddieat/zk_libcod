graphGetNodeIdsAccessibleTo( <graph id>, <node id> )

Module: Graph

Summary:

Returns an array of every node that can reach the given node by following edges forward (includes the node itself). The reverse of graphGetNodeIdsAccessibleFrom. Returns undefined for an invalid or removed node.



Example:

comp = graphGetNodeIdsAccessibleTo(g, goal);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <node id> The target node.
