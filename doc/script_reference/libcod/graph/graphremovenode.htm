graphRemoveNode( <graph id>, <node id> )

Module: Graph

Summary:

Removes a node using a tombstone: the slot stays (so existing node ids keep their meaning), the node is flagged removed, its outgoing edges are dropped and every edge pointing to it is removed. All queries then skip it. Returns true, or false for an invalid or already-removed node.



Example:

graphRemoveNode(g, 5);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <node id> The node to remove.
