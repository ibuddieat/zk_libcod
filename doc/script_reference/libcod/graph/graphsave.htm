graphSave( <graph id>, <fs path> )

Module: Graph

Summary:

Saves the graph as a compact binary file inside your mod folder (relative path, under 64 characters, no ..). Missing folders are created. Returns true on success, false on failure.



Example:

graphSave(g, "scriptdata/graphs/mp_toujane.g2g");



Required Args:

  • 1 : <graph id> The graph to save.
  • 2 : <fs path> Destination path, relative to the mod folder.
