graphFindPath( <graph id>, <start>, <goal>, [<skip nodes>], [<skip node types>], [<skip edge types>], [<max expansions>] )

Module: Graph

Summary:

Runs A* and returns an array of node ids from start to goal. If the goal cannot be reached (or a budget is hit) it returns a best-effort partial path - check whether the last element equals the goal. Returns undefined for invalid arguments.



Example:

path = graphFindPath(g, start, goal);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <start> Start node id.
  • 3 : <goal> Goal node id.

Optional Args

  • 4 : <skip nodes> Array of node ids to treat as blocked.
  • 5 : <skip node types> Bitmask; nodes whose type matches are skipped.
  • 6 : <skip edge types> Bitmask; edges whose type matches are skipped.
  • 7 : <max expansions> Per-call ceiling on nodes explored (partial path if hit).
