graphAutodiscover( <graph id>, <seed origin>, [<grid step>], [<max nodes>] )

Module: Graph

Summary:

Generates a walkable graph with no hand-placed waypoints. Starting at the seed it flood-fills outward on a grid, adding a node wherever a player fits on walkable ground and can reach it from a neighbour, and links walkable grid-neighbours both ways. Every node is reachable from the seed. Returns the number of nodes added. Runs on the main thread - meant for one-time generation, then graphSave.



Example:

n = graphAutodiscover(g, self.origin, 48);



Required Args:

  • 1 : <graph id> The graph to fill (usually empty).
  • 2 : <seed origin> A world position on walkable ground to start from. The call is refused if the seed is not standable.

Optional Args

  • 3 : <grid step> Spacing between nodes in units (default 48; larger = fewer, coarser nodes).
  • 4 : <max nodes> Stop after this many nodes (default sv_graphMaxNodes).
