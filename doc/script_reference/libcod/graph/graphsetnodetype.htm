graphSetNodeType( <graph id>, <node id>, <type> )

Module: Graph

Summary:

Sets a node type bitmask. Returns true, or false for an invalid or removed node.



Example:

graphSetNodeType(g, 5, 2);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <node id> The node.
  • 3 : <type> New type bitmask.
