graphAutodiscoverEx( <graph id>, <seed origin>, [<grid step>], [<max nodes>] )

Module: Graph

Summary:

Enhanced graphAutodiscover. Two upgrades: (1) it seeds the grid from the graph's EXISTING nodes as well, so calling it once per spawn point extends one graph and covers separated areas (other floors, behind doors) that a single seed misses; (2) its links are typed and directional - where a player can walk both ways you get a two-way edge (type 0 flat or 1 step), where a player can only fall one way you get a one-way drop edge (type 2), and a gap too big to fall is not linked. The edge types feed graphFindPath's skip edge types so a bot can be told to avoid drops. Returns the number of new nodes added. Runs on the main thread - meant for one-time generation, then graphSave.



Example:

n = graphAutodiscoverEx(g, self.origin, 48);



Required Args:

  • 1 : <graph id> The graph to fill (empty, or extended by an earlier call).
  • 2 : <seed origin> A world position on walkable ground to start from. The call is refused if the seed is not standable.

Optional Args

  • 3 : <grid step> Spacing between nodes in units (default 48; larger = fewer, coarser nodes).
  • 4 : <max nodes> Stop after the graph reaches this many nodes (default sv_graphMaxNodes).
