graphFindClosestNode( <graph id>, <origin>, [<content mask>] )

Module: Graph

Summary:

Returns the id of the node nearest a world position, or undefined if none qualifies. With a content mask, only nodes with a clear locational trace (line of sight) to the position are considered - more expensive.



Example:

n = graphFindClosestNode(g, self.origin);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <origin> World position vector.

Optional Args

  • 3 : <content mask> Trace content mask (e.g. MASK_SHOT) for a line-of-sight check.
