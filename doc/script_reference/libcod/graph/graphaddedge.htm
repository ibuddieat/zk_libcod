graphAddEdge( <graph id>, <from>, <to>, [<type>], [<cost>] )

Module: Graph

Summary:

Adds a directed edge from one node to another. Add both directions for a two-way link. Returns false for a duplicate edge, true otherwise. Cost defaults to the straight-line distance between the two nodes.



Example:

graphAddEdge(g, 0, 1); graphAddEdge(g, 1, 0);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <from> Source node id.
  • 3 : <to> Destination node id.

Optional Args

  • 4 : <type> Edge type bitmask (default 0).
  • 5 : <cost> Custom traversal cost; default is the distance between the nodes.
