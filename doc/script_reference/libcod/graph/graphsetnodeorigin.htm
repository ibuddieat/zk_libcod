graphSetNodeOrigin( <graph id>, <node id>, <origin> )

Module: Graph

Summary:

Moves a node to a new world position and recomputes the distance cost of every edge touching it (both directions), so manually set costs on those edges are reset. Returns true, or false for an invalid or removed node.



Example:

graphSetNodeOrigin(g, 5, (200, 50, 32));



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <node id> The node.
  • 3 : <origin> New world position.
