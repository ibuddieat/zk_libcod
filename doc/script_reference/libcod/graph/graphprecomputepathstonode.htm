graphPrecomputePathsToNode( <graph id>, <goal>, [<skip node types>], [<skip edge types>] )

Module: Graph

Summary:

Runs one reverse search from a goal and caches, for every node, the cost to reach it and the next hop toward it. Afterwards graphFindPath answers any start-to-this-goal (with the same skip masks and no per-call skip-node list) by following the cached hops - no search. Any change to the graph invalidates every cache. Returns true, or false for an invalid or removed goal.



Example:

graphPrecomputePathsToNode(g, flagNode);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <goal> The shared goal node.

Optional Args

  • 3 : <skip node types> Must match the mask you pass to graphFindPath.
  • 4 : <skip edge types> Must match the mask you pass to graphFindPath.
