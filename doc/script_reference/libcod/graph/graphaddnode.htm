graphAddNode( <graph id>, <origin>, [<type>], [<node id>] )

Module: Graph

Summary:

Adds a node at a world position and returns its id. Nodes must be added in order (0, 1, 2 ...), so a GSC array index and its native node id are always the same number. Returns undefined past sv_graphMaxNodes.



Example:

n = graphAddNode(g, (100, 0, 32), 1);



Required Args:

  • 1 : <graph id> The graph.
  • 2 : <origin> World position vector.

Optional Args

  • 3 : <type> A type bitmask you define (default 0).
  • 4 : <node id> The expected next id, checked against the sequential contract.
