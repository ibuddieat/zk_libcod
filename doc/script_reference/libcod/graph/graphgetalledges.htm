graphGetAllEdges( <graph id> )

Module: Graph

Summary:

Returns a flat array of directed edges as [from0, to0, from1, to1, ...] - read two ids per edge. A two-way link appears as two entries.

Returns undefined when the result would exceed the script variable limit (32768 values). Every array element occupies a slot in the engine's global variable pool, and exhausting that pool is a terminal error, so an oversized query is refused rather than served. An autodiscovered map graph can exceed it: prefer a narrower query.



Example:

e = graphGetAllEdges(g);



Required Args:

  • 1 : <graph id> The graph.
