webSocketSendText( <connectionId>, <message> )

Module: WebSocket

Summary:

Sends a text message over an open WebSocket connection. Returns true if the message was queued to be sent, or false if the given connection id is invalid or not currently connected. The connection id is the value returned by webSocketConnect.



Example:

webSocketSendText(level.wsId, "hello");



Required Args:

  • 1 : <connectionId> Connection id returned by webSocketConnect
  • 2 : <message> Text message to send
