webSocketConnect( <url>, <headers>, <onConnect>, <onMessage>, <onClose>, <onError>, [<reconnectMs>], [<pingMs>] )

Module: WebSocket

Summary:

Opens a WebSocket connection to a ws:// or wss:// URL and returns the connection id (0 or greater), or -1 if no slot is free or an argument is invalid. Up to 16 connections can be open at once. The connection is driven on the main thread, so the callbacks run on the server thread and may safely use the script engine.

The <onConnect> callback is called once the handshake completes. <onMessage> is called for every text frame received, with the message as its argument. <onClose> is called when the connection closes, with two booleans (closed by remote, fully disconnected). <onError> is called with a message on any error. By default the connection reconnects automatically after a drop and sends periodic pings to keep itself alive; pass a reconnect delay of 0 to connect only once and a ping interval of 0 to disable pings.



Example:

id = webSocketConnect("wss://example.com/ws", "", ::onConnect, ::onMessage, ::onClose, ::onError);

onConnect()
{
    webSocketSendText(level.wsId, "hello");
}

onMessage(message)
{
    logPrintConsole("ws: " + message + "\n");
}



Required Args:

  • 1 : <url> Target URL, ws:// or wss://
  • 2 : <headers> Extra handshake headers separated by \r\n, or an empty string for none
  • 3 : <onConnect> Script callback called once connected, no arguments
  • 4 : <onMessage> Script callback called per text frame, with (message)
  • 5 : <onClose> Script callback called on close, with (closedByRemote, fullyDisconnected)
  • 6 : <onError> Script callback called on error, with (error)

Optional Args

  • 1 : <reconnectMs> Delay in milliseconds before reconnecting after a drop. Default 2000. 0 disables auto-reconnect
  • 2 : <pingMs> Interval in milliseconds between keepalive pings. Default 15000. 0 disables pings
