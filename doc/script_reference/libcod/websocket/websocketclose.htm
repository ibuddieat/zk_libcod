webSocketClose( <connectionId> )

Module: WebSocket

Summary:

Requests the given WebSocket connection to close and disables its auto-reconnect. Returns true if the connection id was valid, false otherwise. The close is completed on the next server frame; the connection's <onClose> callback is still called. The connection id is the value returned by webSocketConnect.



Example:

webSocketClose(level.wsId);



Required Args:

  • 1 : <connectionId> Connection id returned by webSocketConnect
