getHWID()

Module: Player

Summary:

Gets the 32-bit hardware id a CoD2x client reports in its cl_hwid dvar, the same value the player sees as cl_hwid in their own console. Returns 0 for stock and 1.x clients and for bots, which do not report one. The value is client-supplied and not authenticated, so it should be treated as a best-effort identity signal only and never as proof of who a player is. See also getHWID2 and getCod2xProtocol.



Call this on:

The player



Example:

hwid = player getHWID();
