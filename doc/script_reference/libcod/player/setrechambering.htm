setRechambering( <bool>, <weapon slot> )

Module: Player

Summary:

Sets the rechambering state for the specified weapon slot. Does not alter the boltAction setting of the affected weapon. The weapon slot parameter is optional, by default the currently used weapon slot is affected. Returns false if the specified weapon slot is "none" or if the specified weapon has boltAction disabled.



Call this on:

The player



Example:

player setRechambering(true, "primary");



Required Args:

  • 1 : <bool> True or false to enforce the desired rechambering state


Optional Args

  • 1 : <weapon slot> Valid weapon slots are "primary" and "primaryb". Default is the currently used weapon slot
