getCod2xProtocol()

Module: Player

Summary:

Gets the CoD2x version a client tells in its protocol_cod2x dvar. Returns 0 for clients that are not running CoD2x (stock and 1.x clients) and for bots, so it can be used to tell whether a player is on a CoD2x client. A CoD2x client keeps reporting this value even when it connects to a 1.3 server, where the underlying game protocol downgrades to 118. See also getHWID.



Call this on:

The player



Example:

if (player getCod2xProtocol() > 0)
    iprintln("player is on a CoD2x client");
