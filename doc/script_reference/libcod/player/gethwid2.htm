getHWID2()

Module: Player

Summary:

Gets the 32-character hardware id a CoD2x client reports in its cl_hwid2 dvar. Returns an empty string for stock and 1.x clients and for bots, which do not report one. Like getHWID this is client-supplied and not authenticated, so it should be treated as a best-effort identity signal only. The sv_cod2x_require_hwid dvar can reject clients that do not present a valid one.



Call this on:

The player



Example:

hwid2 = player getHWID2();
