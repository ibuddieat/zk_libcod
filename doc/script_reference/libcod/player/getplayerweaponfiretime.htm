getPlayerWeaponFireTime( <weapon name> )

Module: Player

Summary:

Returns the player's individual fire time for the given weapon in ms, as set with setPlayerWeaponFireTime. Returns zero if the player uses the weapon's own value (see getWeaponFireTime).



Call this on:

The player



Example:

fireTime = player getPlayerWeaponFireTime(weaponName);



Required Args:

  • 1 : <weapon name>: (string) The weapon name for this weapon


Deprecated Args:

  • 1 : <id> Weapon ID (available for backwards compatibility). You can get it with getLoadedWeapons
