setPlayerWeaponFuseTime( <weapon name>, <fuse time> )

Module: Player

Summary:

Per-player version of setWeaponFuseTime: sets the grenade fuse time in ms of the given weapon for this player only, without affecting other players. A value of 0 (or negative) clears the override. Accepts a weapon name or, for backwards compatibility, a weapon id. Returns true on success. See also getPlayerWeaponFuseTime.



Call this on:

The player



Example:

player setPlayerWeaponFuseTime("frag_grenade_american_mp", 2500);



Required Args:

  • 1 : <weapon name>: (string) The weapon name for this weapon
  • 2 : <fuse time> New fuse time to set in ms (0 clears the override)


Deprecated Args:

  • 1 : <id> Weapon ID (available for backwards compatibility)
