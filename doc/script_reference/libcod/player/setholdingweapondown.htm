setHoldingWeaponDown( <enabled> )

Module: Player

Summary:

Enables/disables the weapon put away state (visually holding the current weapon down) for the player. Sets the weapon put away animation and blocks other weapon actions (e.g., shooting, switching weapons) until the state is disabled or the player dies. Turrets can be entered, the state is reinstated after leaving the turret. Prevents the player from picking up a weapon (ammo is still picked up). Returns true on success, otherwise (i.e., if the put away state is already enabled or if the player currently holds no weapon) false.



Call this on:

The player



Example:

player setHoldingWeaponDown(true);



Required Args:

  • 1 : <enabled> Flag stating whether the weapon put away state should be enabled
