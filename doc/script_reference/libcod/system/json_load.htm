json_load( <fs path> )

Module: System

Summary:

Reads a JSON file from the engine filesystem (fs_homepath / fs_basepath / loaded .iwds), parses it, and returns the resulting GSC value. Returns undefined if the file is missing, unreadable, or contains malformed JSON.



Example:

wp = json_load("verindra/bots/waypoints/mp_carentan.json");
if(isDefined(wp))
    iprintln(wp["nodes"].size + " waypoint nodes loaded");
else
    iprintln("no waypoint file yet");



Required Args:

  • 1 : <fs path> Path relative to the mod root (fs_game). The engine also searches fs_basepath and loaded .iwd archives.

Returns:

The parsed value on success, or undefined if the file does not exist, cannot be opened, is empty, or fails to parse. Always wrap the result with isDefined() before use.


Notes:

  • Missing file returns undefined silently (no log spam, so the "try-load" pattern is cheap).
  • Malformed JSON returns undefined and writes a stackError to the console.
  • Synchronous, blocks the script thread until the file is read and parsed. Keep individual files in the kilobyte range to avoid frame hitches.
