json_parse( <json string> )

Module: System

Summary:

Parses a JSON string and returns the value as a native GSC structure (array / struct / string / int / float / undefined). Returns undefined if the input is malformed.

Value mapping: JSON object <-> GSC string-keyed array, JSON array <-> GSC integer-indexed array, JSON number → GSC int (if integral and 32-bit) else float, JSON true/false → GSC 1/0, JSON null → GSC undefined.



Example:

v = json_parse("{\"name\":\"bot1\",\"hp\":100,\"pos\":[1,2,3]}");
iprintln(v["name"] + " has " + v["hp"] + " hp at z=" + v["pos"][2]);
// -> "bot1 has 100 hp at z=3"



Required Args:

  • 1 : <json string> A string containing valid JSON.

Returns:

The parsed value (array / struct / string / number) on success, or undefined on parse error. Malformed input also logs a stackError to the console.


Notes:

  • JSON null inside a container becomes GSC undefined; that key/index is then absent (GSC arrays can't hold undefined).
  • Maximum nesting depth is 64; deeper input is truncated to undefined.
