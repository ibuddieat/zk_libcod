json_stringify( <value>, [<pretty>] )

Module: System

Summary:

Serializes a GSC value (struct/array/string/number/vector) into a JSON string. pretty = 1 produces a multi-line indented result; default 0 is compact.

Object-vs-array is inferred from key types: only integer-keyed arrays serialize as JSON arrays; everything else (including empty containers) emits a JSON object.



Example:

a = [];
a["name"] = "bot1";
a["pos"]  = (12.5, 34.0, 56.0);
s = json_stringify(a, 1);
// -> {
//      "pos": [ 12.5, 34, 56 ],
//      "name": "bot1"
//    }



Required Args:

  • 1 : <value> Any GSC value: struct, array, string, int, float, or vec3.

Optional Args:

  • 2 : <pretty> 0 = compact single-line (default), 1 = indented multi-line.

Returns:

A JSON string. Returns undefined only on internal allocation failure (effectively unreachable).


Notes:

  • An empty GSC array serializes as {} (empty array and empty struct are indistinguishable in GSC).
  • Sparse or non-zero-based integer-keyed arrays are compacted. a[5]=x serializes as ["x"]; the original index is lost because JSON arrays are dense.
  • GSC vec3 values are emitted as a 3-element JSON array.
  • Whole-number floats (3.0) round-trip back as INT (3) after a subsequent json_parse.
