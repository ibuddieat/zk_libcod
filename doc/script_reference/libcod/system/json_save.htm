json_save( <fs path>, <value>, [<pretty>] )

Module: System

Summary:

Serializes a GSC value to JSON and writes it to the engine filesystem under fs_homepath/<mod>/. pretty = 1 produces indented multi-line JSON; default 0 is compact. Intermediate directories in the path are created by the engine if missing. Returns 1 on success, 0 on failure.



Example:

stats = [];
stats["Alice"] = makeStat(42, 17);
stats["Bob"]   = makeStat(11, 30);
ok = json_save("stats/players.json", stats, 1);
if(!ok)
    logPrintConsole("could not write players.json\n");



Required Args:

  • 1 : <fs path> Destination path relative to the mod root (fs_homepath/fs_game).
  • 2 : <value> Any GSC value to serialize (struct, array, string, int, float, vec3).

Optional Args:

  • 3 : <pretty> 0 = compact single-line (default), 1 = indented multi-line.

Returns:

1 on a successful write, 0 on any failure (open / write error, allocation failure). On open failure, a stackError is also logged.


Notes:

  • Writes through the engine FS, so the file always lands inside the mod's fs_homepath sandbox.
  • Synchronous, blocks the script thread until the file is fully written. Keep individual files modest.
